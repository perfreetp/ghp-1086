## 1. 产品概述

派对反应小游戏合集是一个面向朋友聚会场景的多人实时互动游戏平台。通过大屏显示房间，玩家通过手机扫码加入，提供多种反应类小游戏，支持实时对战、积分排行、惩罚机制等完整聚会玩法。

- **核心目标：让线下聚会场景的互动体验升级，提供无需下载、即开即玩的多人游戏合集
- **目标用户**：朋友聚会、家庭派对、团建活动等2-20人规模的线下社交场景
- **产品价值**：解决聚会破冰、活跃气氛、提供结构化的互动娱乐内容

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|---------|
| 主持人 | 创建房间自动成为主持人 | 开始/暂停游戏、选择游戏、设置回合数、踢出玩家、切换观众模式 |
| 玩家 | 扫码输入房间号加入 | 编辑昵称头像、参与游戏、查看战绩 |
| 观众 | 扫码加入选择观战模式 | 观看游戏、不参与计分 |

### 2.2 功能模块

1. **大厅页面**：创建房间、加入房间（输入房间码）、游戏介绍、快速开始入口
2. **房间页面**：房间码展示、二维码、玩家列表、玩家管理入口、游戏选择、设置入口
3. **游戏选择页面**：4款小游戏卡片（抢答拍手、颜色陷阱、真假按钮、节奏跟点）、回合数设置、游戏规则说明
4. **游戏进行页面**：实时游戏画面、倒计时、玩家操作区、游戏结果实时渲染
5. **结算页面**：单局结算、单局回放、总分排行、惩罚卡抽取、下一局/返回房间
6. **玩家管理页面**：玩家列表、踢人、转让主持人、切换观众/玩家身份
7. **设置页面**：音效开关、游戏规则设置、分享战绩、返回大厅

## 3. 核心流程

```mermaid
flowchart TD
    A["用户进入大厅"] --> B{"创建房间/加入房间"}
    B -->|创建房间| C["生成6位房间码"]
    B -->|加入房间| D["输入房间码"]
    C --> E["进入房间页面"]
    D --> E
    E --> F["玩家扫码/输入加入"]
    F --> G["主持人选择游戏+设置回合"]
    G --> H["游戏进行中"]
    H --> I{"游戏结算"]
    I -->|多回合| H
    I -->|游戏结束| J["总分排行+惩罚卡"]
    J --> K["战绩分享海报"]
```

### 3.1 游戏流程详情

1. **创建房间流程**：主持人在大厅输入昵称 → 选择头像 → 点击创建房间 → 系统生成6位房间码 → 进入房间页面 → 展示二维码和房间码 → 等待玩家加入

2. **加入房间流程**：玩家扫码或输入房间码 → 输入昵称选择头像 → 加入房间 → 房间列表显示新玩家 → 等待开始游戏

3. **游戏进行流程**：主持人选择游戏类型 → 设置回合数和赛制 → 开始游戏 → 倒计时 → 游戏进行 → 实时同步玩家操作 → 判定结果 → 更新得分/淘汰 → 进入结算

4. **结算流程**：单局结束 → 展示本局排名 → 累计分数 → 抽取惩罚卡（可选）→ 选择下一局或分享战绩或返回房间

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色霓虹风格，紫粉渐变为主色（#FF2288 到 #8822FF），搭配荧光青（#00FFCC）和警示黄（#FFDD00）
- **辅助色**：深背景（#0F0A1F）、卡片半透明玻璃拟态风格
- **按钮风格**：圆润大按钮、渐变填充、悬浮放大动效、按压反馈
- **字体**：显示字体使用 Space Grotesk（标题）+ Noto Sans SC（正文）
- **布局**：大屏端采用居中大气布局，移动端紧凑触控友好
- **图标风格**：圆润线性图标搭配emoji增强趣味性
- **动效**：页面切换滑动动画、游戏反馈弹跳动画、得分数字滚动动画

### 4.3 响应式设计

- **桌面大屏端（1920x1080及以上**：全屏沉浸式布局、元素大气、信息密度低
- **平板端（768-1024**：双栏布局自适应
- **移动端（375-768）**：单列触控优化、按钮尺寸≥44px、字号适配
- **触摸优化**：所有可点击元素≥44x44px、触控反馈动效

### 4.4 4款小游戏设计规范

1. **抢答拍手**：大屏显示题目/图片，玩家手机点击"拍手"按钮，最快者得分，误触扣分。大按钮、倒计时、快速反馈

2. **颜色陷阱**：大屏显示颜色词汇（文字颜色与文字含义不同），玩家选择文字"是/否"按钮，限时作答。Stroop效应陷阱

3. **真假按钮**：大屏随机出现真按钮和假按钮（干扰项），玩家需在限时内只点击真按钮。多按钮随机位置、倒计时

4. **节奏跟点**：大屏节拍下落，玩家在节拍到达判定线时点击。下落节奏游戏、Perfect/Good/Miss判定
